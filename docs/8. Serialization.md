# SERIALIZATION

## Introduction

Serialization and deserialization of ``Ito`` hierarchies is easy to accomplish in Pawpaw, which offers native support for both:

 * Pickling
 * JSON

In either case, support for any dynamically ascribed ``.value`` methods are not serializable[^lambda_pickling].

## Pickling

```python
>>> import pickle
>>> from pawpaw import Ito
>>> s = 'See Jack run.'
>>> i = Ito(s, desc='my desc')
>>> i.children.add(*i.str_split())
>>> pickle_data = pickle.dumps(i)
>>> j = pickle.loads(pickle_data)
>>> len(j.children)
3
```

## JSON

JSON serialization in Pawpaw is done using the ``Ito.JsonEncoder``.  This class derives from ``json.JSONEncoder``, and offers specialized behavior through two additional parameters in the contstructor:

```def __init__(self, *json_args, stringless: bool = False, full_tree: bool = True, **json_kwargs)```

1. Parameter ``stringless`` indicates if ``.string`` should be serialized or not.  Stringless serialization has the advantages:

* The resulting json will be reduced in size
* The serialized Ito data can exist without the need for the same level of access control as the underlying ``.string``, which can be persisted elsewhere.  This can also be useful of the ``.string`` value is aleady persisted elsewhere (regardless of its confidentiality) in which case persisting it with the ``Ito`` data would be redundant. 

If you do not opt for stringless json encoding, the resulting output conserves memory by saving the string data for a hierarchy once, since a given ``Ito`` and its children all share the same value.

2. Parameter ``full_tree`` indicates if the full geneology of the underlying Ito should be serialized.  This might be necessary if you need to perform plumule queries against the deserialized ``Ito``, which may require traversal up and down the full tree.

### Ito.JsonEncoder

For serialization that includes string data, use the normal the python json ``.dump(s)``
and ``.load(s)`` methods, passing the ``Ito.JsonEncoder`` class and ``Ito.json_decoder``
method to each respectively:

```python
>>> import json
>>> json_data = json.dumps(i.children[0], cls=Ito.JsonEncoder, stringless=True, full_tree=True, indent='  ')
>>> print(json_data)
{
  "__type__": "pawpaw.ito.Ito",
  "__version__": "1.0.1",
  "path": "./*[i:0]",
  "ito": {
    "span": [
      0,
      13
    ],
    "desc": "my desc",
    "children": [
      {
        "span": [
          0,
          3
        ],
        "desc": "my desc",
        "children": []
      },
      {
        "span": [
          4,
          8
        ],
        "desc": "my desc",
        "children": []
      },
      {
        "span": [
          9,
          13
        ],
        "desc": "my desc",
        "children": []
      }
    ]
  }
}
```

JSON deserialization is accomplished using the ``Ito.JsonDecoderHook``.  Note that if you performed stringless serialization, you must supply a ``string`` paramater to this class:

```
>>> j = json.loads(json_data, object_hook=Ito.JsonDecoderHook(string=s))
>>> print(j)
See
>>> print(j.find('....'))  # root
See Jack run.
>>> print(j.find('>'))  # Next sibling
```

[^lambda_pickling]: The python pickle library supports neither lambdas nor methods not-defined at the top level of a module.  See `Python pickle docs
<https://docs.python.org/3/library/pickle.html/>` for more info.
